# Changelog

All notable user-visible changes are recorded here. This project follows
semantic versioning while pre-1.0 versions may still refine public contracts.

## [Unreleased]

## [0.2.0] - 2026-09-05

- Added a validated JSON configuration for language- and team-specific label
  keyboard shortcuts while retaining the existing bindings as the default.
- Made save-and-continue advance to the next pending document, restored the
  selected document and span across undo/redo, and documented the review
  settings and synthetic interface preview.

## [0.1.0] - 2026-08-17

- Published the first externally supported MedDeID Annotate release.
- Added public installation, compatibility, licensing, and verification
  metadata.
- Established independent CI and immutable release artifacts.
